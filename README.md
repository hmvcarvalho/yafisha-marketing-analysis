# yafisha-marketing-analysis
Marketing spend optimization analysis for Y.Afisha. Covers product metrics (DAU/MAU), cohort retention, LTV, CAC and ROI by source — with actionable recommendations.

## Setup

```bash
python -m venv .venv
```

**Activate the virtual environment:**

- Windows: `.venv\Scripts\activate`
- macOS/Linux: `source .venv/bin/activate`

```bash
pip install -r requirements.txt
```
